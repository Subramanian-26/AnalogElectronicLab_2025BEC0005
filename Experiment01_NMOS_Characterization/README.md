# Experiment 01 – NMOS Characterization

## Aim

To characterize an NMOS transistor using Cadence Virtuoso and Spectre.

## Design Specifications

- NMOS Model: nmos1v
- Technology: gpdk090
- W = 1 µm
- L = 100 nm
- VGS sweep: 0 V to 1.2 V
- VDS sweep: 0 V to 1.2 V

## Circuit Description

The NMOS transistor is configured for DC characterization using VGS and VDS voltage sources.

## Simulation Procedure

The circuit was simulated using Cadence Virtuoso and Spectre.

## Results

The VGS transfer characteristic and VDS output characteristics were obtained.

## Observations

Drain current increases with increasing VGS and VDS.

## Conclusion

The NMOS transistor was successfully characterized using Cadence Virtuoso.
